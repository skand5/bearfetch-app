# Shipaton 2026 submission checklist

Target: RevenueCat Shipaton Next Gen Award.

## Repository requirements

- Public GitHub repository.
- Visible open-source [LICENSE](../LICENSE).
- Setup instructions in [README](../README.md) and [docs/SETUP.md](SETUP.md).
- No real local config, signing material, service credentials, or child data in
  current files or Git history.
- Public repo security features enabled: secret scanning, push protection,
  Dependabot alerts, and private vulnerability reporting.

## Product proof to verify

- RevenueCat Test Store purchase works in fresh development build.
- `bearfetch_progress_insight_lifetime` is attached to current offering as
  `$rc_lifetime`.
- `progress_insight_requests` entitlement activates after purchase and after
  Restore purchase.
- Demo build matches video and screenshots.
